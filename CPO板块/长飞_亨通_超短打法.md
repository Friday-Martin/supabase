# 超短打法:满仓 长飞光纤(601869) + 亨通光电(600487)

> 前提:仓位永远只在这两只里(满仓持有底仓)。数据来自 TickFlow,样本 ~600 交易日(2024–2026,AI 上行 regime)。
> **关键:因为你长期持有底仓,可以做 T(T+0 回转)——卖昨日底仓、当日买回等量,在 T+1 下合法吃到日内波动。** 这让下面的"日内规律"对你可执行(对空仓起步者不可执行)。
> **声明:研究性质,非投资建议。数字为样本内统计、未扣成本(双边约 0.1–0.2%)、强 regime 依赖,熊市大概率失效。**

---

## 1. 两只票的"脾气"(决定分工)

| 维度               | 长飞 601869                 | 亨通 600487                                 |
| ------------------ | --------------------------- | ------------------------------------------- |
| 角色               | **进攻 / 弹性仓**           | **防守 / 底仓**                             |
| 主业属性           | 预制棒-光纤-光缆龙头,弹性大 | 光纤光缆+**海缆**+电网+硅光,题材杂、beta 低 |
| 日波动 / 振幅      | 3.89% / **4.91%**           | 3.09% / 3.92%                               |
| 日均成交额         | 12.1 亿                     | **23.7 亿**(更能装、滑点小)                 |
| 对美股 CPO beta(r) | **0.27(0.21)**              | 0.13(0.13)                                  |
| 涨停频率 / 触板    | **5.5% / 8.5%**             | 1.7% / 3.0%                                 |
| 涨停次日           | **+3.66% / 胜率 70%**       | +3.36% / 60%(样本仅10)                      |
| 隔夜段累计贡献     | **−5%(拖累)**               | +26%(不拖累)                                |

**结论:长飞做进攻(动量、反包弹性大、对美股更敏感);亨通做底仓(抗跌、容量大、联动钝,更跟自身海缆/电网题材)。**

## 2. 数据里最稳的三条可交易规律

### 规律 A:**低开反包**(最稳,两只都成立)

- 长飞 低开>1% → 当日日内 **+1.41% / 胜率 59%**;亨通 **+1.30% / 胜率 60%**。
- 美股强跌夜后:两只都低开(−0.8% 左右),但日内修复 +0.57%/+0.59%,全天仅 −0.34%/−0.16%(**抗跌**)。
- **打法(做T):** 美股跌夜 / A 股低开 → **不恐慌减仓,反而低吸加仓**,午后或尾盘把昨日底仓的等量卖出锁差价(或留到次日)。这是这两只最确定的超短 edge。

### 规律 B:**高开兑现**(长飞尤其明显)

- 长飞 高开>1% → 日内 **胜率仅 46%**(跌多于涨),即高开容易回落。
- **打法(做T):** 高开(尤其 >3%)→ **开盘/早盘把底仓高抛**,盘中回踩再买回,降成本;**不要追高开**。

### 规律 C:**涨停动量 / 连板**(长飞专属,亨通样本不足)

- 长飞 涨停次日 **+3.66% / 胜率 70%**(33 次);封板逻辑顺时动量延续。
- **打法:** 长飞放量涨停且板上封单稳 → 持有不做 T、甚至加仓博次日溢价;**不要在涨停日高抛**(会丢动量)。亨通涨停太少(1.7%),不套用此逻辑。

## 3. 美股信号怎么用(过滤器,不是择时)

美股 CPO 隔夜涨跌对这两只的作用是"**定当日基调 + 缺口方向**",**红利锁在缺口里你抓不到**(规律见 CPO 实证报告),所以美股信号只用来决定"今天做 T 偏多还是偏空、要不要参与":

| 隔夜美股 CPO | 长飞当日倾向                    | 亨通当日倾向       | 做 T 方向                           |
| ------------ | ------------------------------- | ------------------ | ----------------------------------- |
| 强涨(≥+3%)   | 全天均值 +1.85%,偏强            | +1.19%,钝          | 偏多:少高抛、回踩低吸为主;别追高开  |
| 强跌(≤−2%)   | 低开但日内修复,全天 −0.34%      | 全天 −0.16%,更抗跌 | **低开反包(规律A)**:低吸,尾盘减底仓 |
| 平           | 看自身题材(海缆/算力)与板块情绪 | 同左               | 区间高抛低吸                        |

> 注意:长飞对美股敏感度(0.27)≈ 亨通的两倍,所以"美股驱动的日子"重心放长飞;"美股没方向、靠自身海缆/电网/政策的日子"亨通可能独立走。

## 4. 两只之间:强弱切换(不是对冲)

- 同日相关 r=**0.628**(高度同向),且无日级领先滞后 → **它们一起涨跌,不能互相对冲**。
- **切换逻辑:** 板块情绪起、量能放大(进攻) → 把仓位往**长飞**倾斜(beta 高、弹性大);情绪退潮 / 避险 / 缩量(防守) → 往**亨通**倾斜(抗跌、隔夜不拖累、容量大)。
- 盘中谁先放量拉升就阶段性偏向谁(分钟级领先需 tick 验证,日线上两者同步)。

## 5. 一日操作节奏(满仓做 T 模板)

```
盘前:  看隔夜美股 CPO(强涨/强跌/平)→ 定当日基调(表3)
09:15-09:25 竞价:
        大幅高开(>3%,尤其长飞)→ 准备开盘高抛底仓一部分(规律B)
        明显低开(美股跌夜居多)→ 准备低吸(规律A),不杀跌
09:30-10:00:
        高开冲高乏力/破均价 → 高抛兑现
        低开探底企稳(不破前低)→ 低吸加仓
盘中:   长飞封涨停且封单稳 → 持有/加,不做T(规律C)
        否则 → 沿分时均价 高抛低吸 做T,破均价-1.5% 减
尾盘:   把当日做T的反向腿平掉(买回/卖出),底仓过夜
        隔夜段对长飞是负贡献(−5%)→ 高位/冲高日尾盘适度减底仓
```

## 6. T+1 可执行收益(参考,美股强涨夜后,买 d 开盘→卖 d+1 收盘)

|      | 强涨夜后          | 无条件       |
| ---- | ----------------- | ------------ |
| 长飞 | +1.38% / 胜率 50% | +1.10% / 50% |
| 亨通 | +0.85% / 胜率 51% | +0.78% / 51% |

> 这是"从空仓追进去持 1 夜"的口径,edge 薄(看美股≈不看美股)。**你的超额主要来自做 T(规律 A/B)和长飞的动量(规律 C),不是靠追隔夜。**

## 7. 风控红线

1. **强 regime 依赖**:低开反包、涨停动量都是牛市产物,指数走坏 / 连续低开不反包 → 立刻收手,降到底仓。
2. **做 T 纪律**:破分时均价 −1.5% 不补、不扛;长飞振幅 ~5%,单笔做 T 止损要快。
3. **隔夜对长飞是负贡献**:能日内了结的差价别留到隔夜赌;长飞底仓在亢奋冲高日尾盘适度减。
4. **流动性**:大资金优先亨通(成交额 23.7 亿 > 长飞 12.1 亿)。
5. **涨停连板样本**:长飞 33 次尚可,亨通仅 10 次——亨通别套连板逻辑。
