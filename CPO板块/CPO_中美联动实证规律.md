# CPO 中美联动 · 实证规律(真实数据找规律)

> 数据源：TickFlow API(真实日线/分钟线),`x-api-key` 鉴权,key 从环境变量读取(未硬编码)。
> 样本：**573 个交易日,2024-01-22 ~ 2026-06-09**。美股篮子 10 只、A 股篮子 10 只(等权)。
> 复现：`CPO板块/quant/*.py`,需 `export TICKFLOW_API_KEY=...` + `pip install tickflow pandas numpy matplotlib`。
> **声明：以下是数据里"实际存在的统计规律",不是收益承诺。样本处于 2024–2026 AI 大牛市,存在强 regime 依赖,详见第 5 节。不构成投资建议。**

---

## 0. 一句话结论(先把答案给你)

你的假设"**美股 CPO 大涨 → 次日 A 股大涨**"——**统计上成立,但几乎不可交易**。原因:**全部联动都锁死在你抓不到的"开盘缺口"里;而你唯一能交易的"开盘后日内",和美股信号的相关性几乎为零(r=0.014)。** 更反直觉的是:**吃这个隔夜缺口,2.5 年累计是亏的(−35%);A 股 CPO 的钱(+1719%)几乎全是"日内"赚的。**

## 1. 篮子构成

|           | 标的                                                                                                                               |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 美股 (10) | NVDA, AVGO, COHR, LITE, FN, CRDO, MRVL, AAOI, ANET, POET                                                                           |
| A股 (10)  | 中际旭创300308, 新易盛300502, 天孚通信300394, 光迅002281, 太辰光300570, 博创300548, 源杰688498, 剑桥603083, 华工000988, 光库300620 |

时差对齐:美股 D 日收盘(北京 D+1 凌晨)→ A 股 D+1 日 09:30 才首次定价。所以对每个 A 股日,取"严格早于它的最近一个美股交易日"的 close-to-close 收益作为隔夜信号。

## 2. 验证成立的规律(real, 可信)

### 规律 ①：传导真实存在,且**全部集中在开盘缺口**

| 关系                                  | Pearson r      |
| ------------------------------------- | -------------- |
| 美股隔夜 → A股**开盘缺口**(open/昨收) | **+0.482** 强  |
| 美股隔夜 → A股**全天**(收/昨收)       | +0.250 中      |
| 美股隔夜 → A股**日内**(收/开)         | **+0.014 ≈ 0** |

> 含义:美股的信息,在 A 股 **09:15–09:25 集合竞价那一跳**里被一次性定价完。开盘后,美股信号再也"说不上话"。

### 规律 ②：单向传导,美股领先 A 股,A 股不领先美股

- corr(美股 cc(t-1), A股 cc(t)) = **+0.339**(隔夜主通道)
- corr(A股 cc(t-1), 美股 cc(t)) = **−0.049 ≈ 0**(A 股不预测美股)
- 同日历日 corr = +0.136

### 规律 ③：方向胜率明确(美股强涨夜 = 隔夜信号 ≥80 分位,阈值 ≈ +3%)

| 美股强涨夜后 A 股 | 数值                    |
| ----------------- | ----------------------- |
| 开盘**高开**比例  | **76%**                 |
| 开盘缺口均值      | +0.92%                  |
| 全天红盘比例      | 66%,全天均值 **+1.66%** |
| 日内(收/开)均值   | +0.74%,**翻红仅 57%**   |

> "次日高开"是大概率(76%);但"高开之后还涨"只有抛硬币水平(57%)。

### 规律 ④：传导**逐年增强**(产业链一体化 + 资金套利成熟)

| 年份       | gap 耦合 r | 美股强涨夜后 A 股日内均值 |
| ---------- | ---------- | ------------------------- |
| 2024       | 0.26       | +0.40%                    |
| 2025       | 0.56       | +0.57%                    |
| 2026(至今) | **0.67**   | **+1.55%**                |

### 规律 ⑤：个股敏感度排序 = 印证基本面映射

对美股信号最敏感(次日全天 beta / 相关 r):**新易盛(0.37/0.26)、中际旭创(0.34/0.26)、博创、太辰光、天孚**;最钝:**华工(0.14)、光迅(0.15)**。
→ **纯光模块/器件龙头(北美收入占比高)联动最强;多元化标的联动最弱**,与产业链事实一致。

### 规律 ⑥:下行缺口更猛,但日内有修复(不对称)

- per-unit 弹性:美股为负时 beta=**0.45** > 美股为正时 beta=0.27 → **大跌之夜,A 股开盘跳空更狠**。
- 但日内修复明显:**美股强跌夜后,A 股日内均值仍 +0.74%、43% 走出"低开高走"**;篮子低开 <−0.5% 时,日内均值 +0.60%、胜率 57%(n=230)。
- 净效果:美股强涨→A 全天 +1.66%,美股强跌→A 全天仅 −0.59%(跌夜被日内修复垫住)。

### 规律 ⑦(最反直觉、最关键):收益结构全在日内,隔夜是负贡献

| 持有方式(A 股 CPO 篮子, 2.5年)   | 累计       |
| -------------------------------- | ---------- |
| 全程持有(收-收)                  | +1073%     |
| **只赚日内**(每天开盘买、收盘卖) | **+1719%** |
| **只赚隔夜缺口**(收盘买、次开卖) | **−35%**   |

> 尽管缺口和美股相关性高(r=0.48),但缺口的**无条件均值是负的** → **追隔夜缺口是亏钱方向**;A 股 CPO 的超额几乎全部由日内贡献。(见 `charts/01_return_decomposition.png`)

## 3. 被证伪 / 必须警惕的"伪规律"

### 伪规律 A:"板块共振(广度高)→ 日内续涨"——**未来函数,证伪**

初看:高开>1% 且**全天涨家数**≥70% → 日内 +2.19%/胜率 78%;广度<50% → 日内 −3.63%/胜率 0%。**惊艳但作弊**——"全天涨家数"要收盘才知道,拿它预测日内是循环论证。
换成**开盘缺口广度(9:30 可观测)**重做:corr(开盘广度, 日内)=**+0.020 ≈ 0**;开盘广度≥80% 的高开日,日内仅 +0.72%、胜率 53%(≈基线)。**→ 用可观测的开盘广度,共振效应消失,不可交易。**

### 伪规律 B:"日内稳赚 +0.5%"——**regime 依赖,非 alpha**

全样本日内 +0.56%、且 US 信号几乎无关(r=0.014)。这其实是 **2024–2026 AI 牛市的 beta 漂移**:日内均值逐年抬升(2024 +0.35% → 2026 +0.86%)。**牛市反转后大概率消失甚至反向。这不是"美股联动 alpha",是"牛市 + 隔夜负缺口的镜像"。**

## 4. 如果我是交易员:能落地的做法 + 真实预期(基于本样本)

> 所有数字来自上面的真实统计;**未扣交易成本**(A 股双边约印花税0.05%卖出 + 佣金 + 滑点 ≈ 0.1–0.2%/笔),且**强 regime 依赖**。

| #                               | 做法                         | 数据依据                                                    | 样本内预期       | 诚实评价                                                                                     |
| ------------------------------- | ---------------------------- | ----------------------------------------------------------- | ---------------- | -------------------------------------------------------------------------------------------- |
| **T1 不要追隔夜缺口**           | 看到美股大涨就想抢次日高开   | 规律⑦:吃缺口 2.5年 −35%                                     | **负**           | 最重要的一条:**别做**。缺口你也抢不到(无法在 A 股收盘后、美股开盘前预先建仓)                 |
| **T2 日内方向(开盘买→收盘卖)**  | 牛市 beta + 隔夜负缺口镜像   | 全样本日内 +0.56%/胜率56%;美股强涨夜 +0.74%/57%;2026 +1.55% | 薄(扣成本后更薄) | 本质是 beta,**牛市有效、熊市失效**;美股强涨只是微弱加分                                      |
| **T3 低开反弹(逆向)**           | 美股跌夜/A 股低开 → 日内修复 | 低开<−0.5% 日内 +0.60%/胜率57%;强跌夜日内+0.74%             | 小正             | 比追涨稳;需止损纪律,趋势性下跌日会接刀                                                       |
| **T4 选股替代择时**             | 联动强度个股分化大           | 规律⑤:旭创/新易盛 beta≈0.35 vs 华工0.14                     | 提升弹性         | 要弹性买龙头,要稳健回避钝标的;**选股 > 择时**                                                |
| **T5 多日跟随(弱)**             | 强涨夜后 T+1..T+4 仍有余温   | T+1 +0.58%、T+2 +0.46%,衰减;累计到 T+4 ≈ +3.3%              | 衰减式小正       | 大部分在 T+0(缺口),持有 T+1 后胜率掉到 52%                                                   |
| **T6(关键否定) 缺口套利不可行** | 想在 A 股捕捉缺口            | 时序上 A 股 D−1 收盘(15:00)早于引发缺口的美股 D−1 盘(21:30) | 不可执行         | **A 股现金交易者物理上无法为缺口预先建仓**;要博缺口只能用 A50 期货/中概/港股等隔夜可交易工具 |

**决策树(我会这么做):**

```
看到美股 CPO 大涨 →
  ① 不抢次日高开(缺口抢不到且均值为负)
  ② 若仍处 AI 上行 regime + 想参与 → 09:30 后看盘:
       低开/平开企稳 → T3/T2 日内做多龙头(旭创/新易盛),破均价-1.5% 止损
       大幅高开(>3%) → 大概率兑现,不追,等回踩或放弃
  ③ regime 转弱(指数走坏、缺口连续被吞) → 空仓,联动 alpha 不存在
```

## 5. 必须说清的局限(否则会害你)

1. **Regime 依赖**:样本全程是 AI 大牛市,日内正漂移、传导增强很可能是 regime 产物,熊市会失效/反向。
2. **未扣成本与冲击**:日内 edge 很薄,扣 0.1–0.2%/笔后,T2/T3 的净期望接近噪声;涨停板买不到的收益是虚的。
3. **缺口不可捕捉**:r=0.48 的联动你拿不到(时序错位),报告里反复强调。
4. **样本量**:强事件(美股隔夜≥+3%)115 个,统计够用但非海量;伪规律 A 的反例只有 n=20/8,本身也要打折看。
5. **等权篮子 ≠ 你的持仓**;个股有停牌、涨跌停、并购等噪声。
6. **survivorship**:篮子用当前成分,未做 point-in-time 调整。
