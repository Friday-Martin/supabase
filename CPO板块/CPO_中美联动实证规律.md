# CPO 中美联动 · 实证规律(真实数据找规律)

> 数据源：TickFlow API(真实日线/分钟线),`x-api-key` 鉴权,key 从环境变量读取(未硬编码)。
> 样本：**573 个交易日,2024-01-22 ~ 2026-06-09**。美股篮子 10 只、A 股篮子 10 只(等权)。
> 复现：`CPO板块/quant/*.py`,需 `export TICKFLOW_API_KEY=...` + `pip install tickflow pandas numpy matplotlib`。
> **声明：以下是数据里"实际存在的统计规律",不是收益承诺。样本处于 2024–2026 AI 大牛市,存在强 regime 依赖,详见第 5 节。不构成投资建议。**

---

## 0. 一句话结论(先把答案给你)

你的假设"**美股 CPO 大涨 → 次日 A 股大涨**"——**方向成立(76% 次日高开),但对 A 股现货 T+1 交易者几乎不可交易**。原因:**全部联动锁死在你抓不到的"开盘缺口"里(缺口形成于集合竞价,你入场即被定价);开盘后日内与美股信号的相关性几乎为零(r=0.014);而 A 股 T+1 又不允许当日买卖,你做不到"只吃日内"。** 更反直觉的是(收益归因):**A 股 CPO 的涨幅几乎全在白天交易段产生(日内段归因 +1719%),隔夜跳空段净拖累(−35%)——即"尾盘买、博次日高开"长期亏钱。**

## 2. 验证成立的规律(real, 可信)

### 规律 ①：传导真实存在,且**全部集中在开盘缺口**

| 关系                                  | Pearson r      |
| ------------------------------------- | -------------- |
| 美股隔夜 → A股**开盘缺口**(open/昨收) | **+0.482** 强  |
| 美股隔夜 → A股**全天**(收/昨收)       | +0.250 中      |
| 美股隔夜 → A股**日内**(收/开)         | **+0.014 ≈ 0** |

> 含义:美股的信息,在 A 股 **09:15–09:25 集合竞价那一跳**里被一次性定价完。开盘后,美股信号再也"说不上话"。

### 规律 ②：单向传导,美股领先 A 股,A 股不领先美股

- corr(美股 cc(t-1), A股 cc(t)) = **+0.339**(隔夜主通道)
- corr(A股 cc(t-1), 美股 cc(t)) = **−0.049 ≈ 0**(A 股不预测美股)
- 同日历日 corr = +0.136

### 规律 ③：方向胜率明确(美股强涨夜 = 隔夜信号 ≥80 分位,阈值 ≈ +3%)

| 美股强涨夜后 A 股 | 数值                    |
| ----------------- | ----------------------- |
| 开盘**高开**比例  | **76%**                 |
| 开盘缺口均值      | +0.92%                  |
| 全天红盘比例      | 66%,全天均值 **+1.66%** |
| 日内(收/开)均值   | +0.74%,**翻红仅 57%**   |

> "次日高开"是大概率(76%);但"高开之后还涨"只有抛硬币水平(57%)。

### 规律 ④：传导**逐年增强**(产业链一体化 + 资金套利成熟)

| 年份       | gap 耦合 r | 美股强涨夜后 A 股日内均值 |
| ---------- | ---------- | ------------------------- |
| 2024       | 0.26       | +0.40%                    |
| 2025       | 0.56       | +0.57%                    |
| 2026(至今) | **0.67**   | **+1.55%**                |

### 规律 ⑤：个股敏感度排序 = 印证基本面映射

对美股信号最敏感(次日全天 beta / 相关 r):**新易盛(0.37/0.26)、中际旭创(0.34/0.26)、博创、太辰光、天孚**;最钝:**华工(0.14)、光迅(0.15)**。
→ **纯光模块/器件龙头(北美收入占比高)联动最强;多元化标的联动最弱**,与产业链事实一致。

### 规律 ⑥:下行缺口更猛,但日内有修复(不对称)

- per-unit 弹性:美股为负时 beta=**0.45** > 美股为正时 beta=0.27 → **大跌之夜,A 股开盘跳空更狠**。
- 但日内修复明显:**美股强跌夜后,A 股日内均值仍 +0.74%、43% 走出"低开高走"**;篮子低开 <−0.5% 时,日内均值 +0.60%、胜率 57%(n=230)。
- 净效果:美股强涨→A 全天 +1.66%,美股强跌→A 全天仅 −0.59%(跌夜被日内修复垫住)。

### 规律 ⑦(最反直觉、最关键):收益结构全在日内,隔夜是负贡献

**这是"收益归因",不是三个可执行策略。** 把每天涨跌切成两段看钱在哪段产生:`(1+全程) ≈ (1+隔夜段) × (1+日内段)`,实测 `(1−35%)×(1+1719%) ≈ +1073%`,对得上。

| 口径(A 股 CPO 篮子, 2.5年)         | 累计       | T+1 下可执行?                        |
| ---------------------------------- | ---------- | ------------------------------------ |
| 全程持有(收-收,连续持有)           | +1073%     | ✅ 可(买入持有)                      |
| **日内段**(开→收,白天交易时段贡献) | **+1719%** | ❌ **不可**(同日买卖,违反 T+1)       |
| **隔夜段**(昨收→今开,跳空贡献)     | **−35%**   | ✅ 可("收盘买、次日开盘卖",但长期亏) |

> 两个要点:
>
> 1. **"日内段 +1719%" 是归因,不是策略**——A 股 T+1 不能当日买卖,你无法"只吃日内段"。它说明的是:**A 股 CPO 的涨幅几乎全部在白天交易时段产生,隔夜跳空净拖累。**
> 2. **"隔夜段 −35%" 才是可执行口径**:尾盘买、博次日高开,长期亏钱。即:虽然缺口和美股相关性高(r=0.48),但缺口**无条件均值为负** → **追隔夜高开是亏钱方向**。(见 `charts/01_return_decomposition.png`)

## 3. 被证伪 / 必须警惕的"伪规律"

### 伪规律 A:"板块共振(广度高)→ 日内续涨"——**未来函数,证伪**

初看:高开>1% 且**全天涨家数**≥70% → 日内 +2.19%/胜率 78%;广度<50% → 日内 −3.63%/胜率 0%。**惊艳但作弊**——"全天涨家数"要收盘才知道,拿它预测日内是循环论证。
换成**开盘缺口广度(9:30 可观测)**重做:corr(开盘广度, 日内)=**+0.020 ≈ 0**;开盘广度≥80% 的高开日,日内仅 +0.72%、胜率 53%(≈基线)。**→ 用可观测的开盘广度,共振效应消失,不可交易。**

### 伪规律 B:"日内稳赚 +0.5%"——**regime 依赖,非 alpha**

全样本日内 +0.56%、且 US 信号几乎无关(r=0.014)。这其实是 **2024–2026 AI 牛市的 beta 漂移**:日内均值逐年抬升(2024 +0.35% → 2026 +0.86%)。**牛市反转后大概率消失甚至反向。这不是"美股联动 alpha",是"牛市 + 隔夜负缺口的镜像"。**

## 4. 如果我是交易员:T+1 下能落地的做法 + 真实预期

> **重要前提:A 股 T+1**——当天买入的股票当天不能卖,**最少持有 1 个隔夜**。所以"开盘买、收盘卖"的日内 T+0 在 A 股现货**无法执行**;任何短线都至少吃 1 个隔夜跳空(而隔夜段均值为负,见规律⑦)。
> 美股大涨发生在 A 股收盘后的当晚,你**最早只能次日(d 日)开盘买**(缺口已错过),**最早 d+1 才能卖**。下表均为此真实约束下的可执行口径,**未扣成本**(印花税0.05%+佣金+滑点 ≈ 0.1–0.2%/笔)。

| #                                              | 可执行做法(美股强涨夜后)        | 样本内均值 / 胜率                 | 对照:不看美股 | 诚实评价                                                                                          |
| ---------------------------------------------- | ------------------------------- | --------------------------------- | ------------- | ------------------------------------------------------------------------------------------------- |
| **T1 别追隔夜高开**                            | 尾盘买、博次日高开("隔夜段")    | 2.5年累计 **−35%**                | —             | **最重要:别做。** 缺口红利在你买前已定价,你接的是高开回落                                         |
| **T2 买 d 开盘 → 卖 d+1 开盘**(持1夜)          | 高开后入场、吃 1 夜             | **+0.41%** / 54%                  | +0.49% / 55%  | **看美股还不如不看**——高开后接盘,把利好让给了昨晚持仓者                                           |
| **T3 买 d 开盘 → 卖 d+1 收盘**(持1夜+次日全天) | 同上但多持次日交易段            | **+1.30%** / 54%                  | +1.06% / 55%  | 略优,但主要是 beta;扣成本后变薄                                                                   |
| **T4 低开反弹(逆向)**                          | 美股跌夜/A股低开 → 持1夜博修复  | 低开<−0.5% 次段 +0.60% / 57%      | —             | 比追涨稳;趋势下跌日会接刀,需止损                                                                  |
| **T5 选股替代择时**                            | 联动强度个股分化大              | 旭创/新易盛 beta≈0.35 vs 华工0.14 | —             | 要弹性买龙头、要稳健避钝标的;**选股 > 择时**                                                      |
| **T6(关键否定)缺口套利**                       | 想在 A 股吃那 +0.92%/76% 的缺口 | 不可执行                          | —             | A 股现货**物理上无法**在缺口形成前建仓;要博缺口只能用 **A50 期货 / 港股 / 中概** 等隔夜可交易工具 |

**核心:** 美股涨→A 股跟涨(76% 高开)是真的,但对 **A 股现货 T+1 交易者几乎榨不出超额**——高胜率的 +0.92% 缺口吃不到,而你能执行的"持 1 夜"动作,看美股(+0.41%)反而不如闭眼买(+0.49%)。

**决策树(我会这么做):**

```
看到美股 CPO 大涨 →
  ① 不抢次日高开(缺口抢不到、且尾盘博高开长期为负)
  ② 缺口已在 d 日开盘形成,不追高;若仍处 AI 上行 regime 且想参与:
       d 日低开/平开企稳 → 买龙头(旭创/新易盛),持到 d+1,破均价-1.5% 止损
       d 日大幅高开(>3%) → 大概率兑现回落,等回踩或放弃
  ③ 要交易"隔夜联动"本身 → 用 A50 期货/港股(可隔夜),不要用 A 股现货
  ④ regime 转弱(指数走坏、缺口连续被吞) → 空仓,联动 alpha 不存在
```

## 5. 必须说清的局限(否则会害你)

1. **Regime 依赖**:样本全程是 AI 大牛市,日内正漂移、传导增强很可能是 regime 产物,熊市会失效/反向。
2. **未扣成本与冲击**:日内 edge 很薄,扣 0.1–0.2%/笔后,T2/T3 的净期望接近噪声;涨停板买不到的收益是虚的。
3. **缺口不可捕捉**:r=0.48 的联动你拿不到(时序错位),报告里反复强调。
4. **样本量**:强事件(美股隔夜≥+3%)115 个,统计够用但非海量;伪规律 A 的反例只有 n=20/8,本身也要打折看。
5. **等权篮子 ≠ 你的持仓**;个股有停牌、涨跌停、并购等噪声。
6. **survivorship**:篮子用当前成分,未做 point-in-time 调整。
